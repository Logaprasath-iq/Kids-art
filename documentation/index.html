Little Canvas Documentation

Welcome to the official developer and customization documentation for Little Canvas — Kids Art & Painting Classes / Creative Learning Studio. This premium multi-page HTML5 template is designed for commercial marketplaces, education studios, art academies, and creative workshops.

Customizing Color Tokens

All colors are defined as CSS Custom Properties in assets/css/style.css. Modify the root tokens to re-brand the template instantly:

:root { --primary: #FF5C8A; /* Primary Coral Pink */ --secondary: #6C63FF; /* Royal Studio Purple */ --blue: #35C9FF; /* Sky Blue */ --yellow: #FFD93D; /* Bright Sun Yellow */ --orange: #FF8A3D; /* Clay Orange */ --green: #48D597; /* Mint Green */ --cream: #FFF9E9; /* Warm Studio Canvas */ --dark: #242044; /* Deep Navy Border/Text */ }

Three.js 3D Hero Customization

The interactive 3D hero playground on Home 1 is defined in assets/js/animations.js inside initThreeScene(). It includes a custom extruded paint palette, floating paint brush, 3D pencil, and color spheres that respond smoothly to mouse parallax. It also includes an automatic fallback for mobile devices and non-WebGL environments.

Enabling RTL Mode

To enable Right-to-Left (RTL) mode for Arabic or Hebrew languages, simply set dir="rtl" on the root <html> element:

<html lang="ar" dir="rtl">

The template includes a persistent toggle button in the navbar that remembers the user's preference using localStorage.
